# Native FL effect-slot power

The exact supported Wrapper dispatch data slot is observed without changing native instructions. Every original Dispatcher call, argument, return value and exception is forwarded once. Only the native ID11 enabled-state notification updates a known bound insert. Shared registry and immutable per-generation bindings have process lifetime; retirement closes the old generation before teardown.

Initial power is adopted only at a stopped and drained native mix boundary, after validating the full component/wrapper/tag/plugin chain. One fresh token precedes repeated typed native enabled-byte reads. The initial seed is one-use; later cache publications cannot reseed it. Installation is usable only when the original page protection is restored.

At each qualified source block, Disabled preserves the native original-produced audio. Enabled uses the prepared ARA cache under its existing ticket guards. Unknown holds the source and queues a separately identified STOP request. The model thread rechecks live component and binding pointer, wrapper, generation and current Unknown state immediately before STOP. A completed notification or replaced owner cancels the obsolete request. Power uncertainty does not invalidate or rebuild a coherent ARA cache.

This mechanism is scoped to the exact supported native build. Compiled controls do not establish native third-party compatibility.
